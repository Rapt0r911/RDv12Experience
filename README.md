# RDv12Experience
My first interactive atmospheric shifter


Basically ripped my 7Zip prepped file andbrought it here, as it was too large for typical means. So take what's there, ensure it's .7zip, .zip, .rar etc... and throw it in your mod manager, or unzip in your root folder where the r6 and bin files for Punk2077 are located. 

Left ctrl is your clutch, you can change shift modes, or turn it off, for manual racing gears, use your numbpad or change buttons via LUA or in teh MM menu! Goodluck, this has bug, and needs work, however a solid start.
